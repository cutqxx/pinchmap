# Pinchmap — дизайн-бриф

> Режим: существующая система. Своей дизайн-системы у плагина нет: всё оформление берётся из CSS-переменных и классов темы Obsidian, чтобы карта выглядела родной в любой теме (светлой и тёмной), на ПК, iPad и iPhone. Бриф описывает то, что уже есть в `styles.css`, и задаёт оформление UI фазы 2 «богатые ноды» в тех же рамках.
>
> Обновлено: 2026-11-25 (фаза 2).

## Принципы

1. **Только переменные темы.** Ни одного захардкоженного цвета. Цвета, радиусы, тени, слои и размеры шрифта берутся из переменных Obsidian. У переменных без гарантии во всех версиях есть фолбэк: `var(--font-text-size, 16px)`, `var(--layer-popover, 50)`, `var(--size-4-3, 12px)`, `var(--font-semibold, 600)`, `var(--pinchmap-zoom, 1)`.
2. **Префикс `pinchmap-`** у всех своих классов. Состояния задаются модификаторами `is-*` / `has-*` (`is-selected`, `is-root`, `is-editing`, `is-left`, `is-hidden`, `has-collapse-toggle`). Исключение из фазы 1: `pinchmap-node--drop-target`.
3. **Контент масштабируется, элементы управления — нет.** Нода, текст, картинки и связи живут в `.pinchmap-world` и масштабируются камерой. Элементы управления на нодах (`+`, индикатор свёртывания, иконка ссылки) компенсируют зум через `transform: scale(calc(1 / var(--pinchmap-zoom, 1)))`, поэтому на экране у них всегда один размер.
4. **Зона касания — 44×44px** у всего интерактивного (`.pinchmap-add-button`, `.pinchmap-collapse-toggle`, `.pinchmap-done-button`, `.pinchmap-history-action`). Видимая часть может быть меньше (22px, 18px), а зона касания остаётся 44px.
5. **Системный UI Obsidian, где он есть.** Контекстные меню — `Menu` Obsidian (на мобильных это нижняя шторка), выбор файла — `FuzzySuggestModal`, ошибки — `Notice`, кнопки заголовка — `view.addAction` с иконками Lucide. Свои всплывающие элементы (`.pinchmap-done-bar`, в фазе 2 — бабл ссылки) создаются на уровне документа с `position: fixed` и `z-index: var(--layer-popover)`.
6. **Без анимаций.** Сейчас в плагине нет ни одного transition, и меню Obsidian появляются мгновенно. В фазе 2 это сохраняется: смена состояний происходит сразу, `prefers-reduced-motion` учитывать не нужно, пока анимаций нет.

## Цвета (переменные темы)

| Назначение | Переменная | Где используется |
|---|---|---|
| Фон канваса | `--background-primary` | `.pinchmap-canvas`, поле ввода `.pinchmap-node-input`, подложка `.pinchmap-collapse-mark` |
| Фон ноды и панелей | `--background-secondary` | `.pinchmap-node`, `.pinchmap-done-bar` |
| Рамки | `--background-modifier-border` | рамка ноды, верх панели «Готово», рамка `.pinchmap-collapse-mark` |
| Подсветка цели | `--background-modifier-hover` | фон `.pinchmap-node--drop-target` |
| Акцент | `--interactive-accent` | рамка root, обводка выделения и поля ввода, «+», кнопка «Готово», рамка выделения (`color-mix` 15%) |
| Текст на акценте | `--text-on-accent` | знак «+» |
| Текст | `--text-normal` / `--text-muted` / `--text-faint` | текст ноды / счётчик потомков / связи |
| Цвета нод | `--color-red`, `--color-orange`, `--color-yellow`, `--color-green`, `--color-cyan`, `--color-purple` | через `--pinchmap-color` по `data-pinchmap-color`, красится рамка ноды и связь; без цвета — `--interactive-accent` |

Цвет ноды влияет только на рамку и связь. Содержимое ноды (Markdown, ссылки, теги) его не наследует.

## Типографика

- Шрифт и семейство не задаются: нода наследует шрифт интерфейса Obsidian.
- Текст ноды: `font-size: var(--font-text-size, 16px)`, `line-height: 1.5`.
- Root: `font-size × 1.25`, `font-weight: var(--font-semibold, 600)`.
- Мелкий служебный текст: счётчик свёрнутых потомков 11px, `--text-muted`.

## Размеры и отступы

Своей шкалы отступов нет. Значения, которые уже используются:

| Значение | Где |
|---|---|
| `--pinchmap-node-padding-block: 6px`, `--pinchmap-node-padding-inline: 10px` | внутренние отступы ноды и поля ввода |
| `max-width: 300px`, `min-width: 2em`, `min-height: calc(1.5em + 12px)` | габариты ноды (`width: max-content`) |
| `1px` / `2px` | рамка ноды / рамка root, обводка выделения и ввода; `outline-offset: 2px` |
| `44px` | зона касания элементов управления, высота панели «Готово» |
| `22px` | видимый круг «+» |
| `18px` | видимая метка свёртывания (`border-radius: 9px`) |
| `var(--size-4-3, 12px)` | боковой отступ панели «Готово» |
| `var(--radius-m)` | скругление ноды и поля ввода |

## Компоненты и паттерны (фаза 1)

- **Нода** — `div.pinchmap-node[data-pinchmap-hit=node][data-node-id]`, текст в `span.pinchmap-node-text` (`white-space: pre-wrap`, `overflow-wrap: break-word`). Хит-тест работает через `data-pinchmap-hit` и `data-node-id`.
- **Выделение** — `outline: 2px solid var(--interactive-accent)`, `outline-offset: 2px`, `z-index: 1`.
- **Цель перетаскивания** — пунктирная обводка акцентом и фон `--background-modifier-hover`.
- **Редактирование** — `textarea.pinchmap-node-input` поверх ноды (`inset: 0`), фон `--background-primary`, обводка акцентом. Под ним скрытый (`visibility: hidden`) текст черновика держит размер ноды.
- **Кнопки «+»** — 44px зона, 22px круг акцентного цвета, справа по центру (дочерняя) и снизу по центру (соседняя), компенсация зума с `transform-origin` у края ноды.
- **Индикатор свёртывания** — 44px зона, центр на правом крае ноды (у `.is-left` — на левом), метка 18px. При наведении рамка становится акцентной, текст — `--text-normal`.
- **Панель «Готово»** — `position: fixed` над клавиатурой, `z-index: var(--layer-popover, 50)`. Кнопка 44px без фона и тени, текст акцентный полужирный. `pointerdown` и `mousedown` на кнопке гасятся, чтобы textarea не теряла фокус.
- **Действия в заголовке** — `.view-action.pinchmap-history-action`, 44×44px, неактивное состояние `opacity: 0.4`.
- **DOM** — в `render/` и `editor/` элементы создаются через `container.ownerDocument` (без `createEl` и без глобального `document`). Иконки Lucide через `setIcon` доступны только в `obsidian/`. В `render/` иконку нужно рисовать встроенным SVG.

## Доступность

- Фокус канваса: `.pinchmap-canvas:focus:not(:focus-visible) { outline: none; }`, при навигации с клавиатуры кольцо фокуса остаётся.
- У всех элементов управления зона касания 44×44px.
- Цвет — не единственный сигнал: выделение показывается обводкой, цель перетаскивания — пунктиром, root — толщиной рамки и размером шрифта.
- Контраст обеспечивает тема: используются только её пары текст/фон.

## Фаза 2: богатые ноды

### 1. Markdown внутри ноды

**Структура.** У ноды два слоя содержимого, и в каждый момент видим ровно один (второй скрыт через `display: none`, чтобы не влиять на размер):

- `span.pinchmap-node-text` — сырой текст. Показывается в режиме редактирования (как сейчас, `visibility: hidden` под textarea) и до первого рендера Markdown.
- `div.pinchmap-node-markdown.markdown-rendered` — результат `MarkdownRenderer.render`. Класс `markdown-rendered` подключает стили темы для `strong`, `em`, `code`, `.internal-link`, `.external-link`, `.tag`, `mark`, `.internal-embed`. Нода выглядит так же, как заметка в той же теме.

**Сбросы** (с повышенной специфичностью `.pinchmap-node .pinchmap-node-markdown …`, чтобы перебить тему):

```css
.pinchmap-node .pinchmap-node-markdown {
  font-size: inherit;
  line-height: inherit;
  white-space: normal;          /* line breaks come as <br> from the renderer */
  color: inherit;
}
.pinchmap-node .pinchmap-node-markdown :is(p, h1, h2, h3, h4, h5, h6, ul, ol, blockquote, pre) {
  margin: 0;
}
.pinchmap-node .pinchmap-node-markdown > * + * {
  margin-top: 0.25em;           /* gap between blocks (blank line in source) */
}
.pinchmap-node .pinchmap-node-markdown * {
  pointer-events: none;         /* links/tags/images never handle taps themselves */
}
```

- **Главный инвариант:** нода с обычным текстом без разметки имеет **одинаковый размер** в сыром и отрендеренном виде. Поэтому шрифт и высота строки наследуются, а отступы параграфов обнулены.
- **Жирный, курсив, выделение `==…==`** — как в теме. Внутри root (он уже полужирный) `strong` берёт вес темы.
- **Инлайн-код** — фон, цвет и размер из темы (`--code-background`, `--code-normal`, `--code-size`). Длинный код переносится: `overflow-wrap: anywhere`.
- **Вики-ссылки и внешние ссылки** — цвет темы (`--link-color`, `--link-external-color`), иконка внешней ссылки и вид неразрешённой ссылки (`.is-unresolved`) тоже из темы. Длинные URL переносятся (`overflow-wrap: anywhere`) и не растягивают ноду шире 300px.
- **Теги** — «таблетка» `.tag` из темы.
- **Заголовки** (текст ноды начинается с `#`) — размеры темы (`--h1-size` и др.) в ноде не используются, они относительные: `h1` 1.25em, `h2` 1.125em, `h3`–`h6` 1em. Вес `var(--font-semibold, 600)`, `line-height: 1.3`, цвет `inherit`. Так заголовок в root тоже масштабируется от его 1.25×.
- **Списки** (текст начинается с `1.` или `-`) — `padding-inline-start: 1.25em`, маркеры из темы, без внешних отступов.
- **Блоки кода (`pre`)** — `white-space: pre-wrap`, `overflow: hidden`, ширина не больше ширины ноды.
- **Чекбоксы задач** — видны, но неактивны (`pointer-events: none`). Переключать их по тапу — вне рамок фазы 2.
- Таблицы, выноски и встраивания заметок (`![[Заметка]]`) отдельно не оформляются. Чтобы они не раздували ноду, встраиванию не-картинки задаётся `max-height: 150px; overflow: hidden`. Нужен ли такой рендер вообще — вопрос для спека.
- Ссылки, теги и картинки в ноде не реагируют на касание (`pointer-events: none`). Поэтому нет перехода по ссылке при тапе, нет курсора-руки, подчёркивания при наведении и превью Obsidian по ховеру. Весь тап получает нода. Защиту на уровне событий (preventDefault в фазе захвата) всё равно нужно оставить.

### 2. Миниатюры картинок

`MarkdownRenderer` рисует `![[img.png]]` как `span.internal-embed.image-embed > img`, а `![](url)` — как `img`. Оба случая оформляются одинаково.

**Фиксированная рамка — главное решение против скачков раскладки.** Размер миниатюры известен до загрузки картинки. Нода получает итоговый размер в первом же кадре и не прыгает, когда картинка догружается. Это особенно важно при открытии карты на 200 нод.

```css
.pinchmap-node .pinchmap-node-markdown img {
  display: block;
  box-sizing: border-box;
  width: 200px;
  height: 150px;                 /* 4:3 frame, fixed before load */
  object-fit: contain;           /* whole image visible, never cropped */
  border-radius: var(--radius-s);
  background-color: var(--background-primary);   /* placeholder and letterbox mat */
}
.pinchmap-node .pinchmap-node-markdown .image-embed {
  display: block;
}
```

- **Размер:** рамка 200×150px (4:3) в координатах карты, масштабируется вместе с нодой. Влезает в ширину контента ноды (300 − 2×10 − 2 = 278px). Подсказка размера `![[img.png|100]]` внутри ноды игнорируется: CSS-ширина перебивает атрибут `width`.
- **Пропорции:** `object-fit: contain`. Картинка видна целиком. Вертикальные фото и скриншоты вписываются по высоте, по бокам остаются поля цвета `--background-primary`.
- **Плейсхолдер:** до загрузки видна та же подложка `--background-primary` нужного размера. Спиннеров и анимаций нет.
- **Битая картинка** (ошибка загрузки): рамка остаётся того же размера, `img` получает `.is-broken` и скрывает alt-текст. По центру иконка Lucide `image-off` цвета `--text-faint`, рисует её `obsidian/`. Имя файла видно в `title`. **Файл не найден в хранилище** (`![[нет.png]]`): Obsidian показывает неразрешённое встраивание — оставляем как есть.
- **Несколько картинок:** каждая миниатюра — отдельный блок, они идут столбиком в порядке текста с зазором 0.25em (общее правило `> * + *`, внутри параграфа — `margin-top: 0.25em` у `.image-embed + .image-embed`). Текст до и после картинки переносится на отдельные строки.
- Атрибут `decoding="async"` у картинок желателен. Перерисовывать Markdown при выделении или перетаскивании нельзя.

### 3. Иконка ссылки на ноде

Показывается у ноды, в **сохранённом** тексте которой есть хотя бы одна ссылка (вики или внешняя; ссылки внутри инлайн-кода не считаются, встраивание `![[картинка]]` — не ссылка). Видна всегда, а не только у выделенной ноды. В режиме редактирования скрыта (`.is-editing`).

**Положение — верхний угол ноды со стороны родителя.** Правый край и середину ноды уже занимают индикатор свёртывания и «+» (дочерняя), низ — «+» (соседняя). Свободен только верхний угол со стороны входящей связи:

- нода справа от root (обычный случай) — **левый верхний угол**;
- нода слева от root (`.is-left`), у неё свёртывание слева — **правый верхний угол**;
- root — левый верхний угол.

Центр иконки стоит на вершине угла, иконка наполовину выходит за рамку ноды. Размер ноды из-за неё не меняется, раскладка не пересчитывается.

```css
.pinchmap-link-icon {
  position: absolute;
  top: 0;
  left: 0;
  display: flex;
  align-items: center;
  justify-content: center;
  width: 44px;                   /* touch target */
  height: 44px;
  margin: -22px 0 0 -22px;       /* centred on the corner */
  cursor: pointer;
  transform: scale(calc(1 / var(--pinchmap-zoom, 1)));
}
.pinchmap-node.is-left > .pinchmap-link-icon {
  left: 100%;
}
.pinchmap-node.is-editing > .pinchmap-link-icon {
  display: none;
}
.pinchmap-link-mark {             /* visible 18px badge, same language as .pinchmap-collapse-mark */
  display: flex;
  align-items: center;
  justify-content: center;
  box-sizing: border-box;
  width: 18px;
  height: 18px;
  border: 1px solid var(--background-modifier-border);
  border-radius: 50%;
  background-color: var(--background-primary);
  color: var(--text-muted);
}
.pinchmap-link-mark svg {
  width: 12px;
  height: 12px;
}
.pinchmap-link-icon:hover .pinchmap-link-mark {
  border-color: var(--interactive-accent);
  color: var(--text-normal);
}
```

- **Иконка** — Lucide `link` встроенным SVG (`render/` не может вызывать `setIcon`): `stroke="currentColor"`, `fill="none"`, `stroke-width` 2, `aria-hidden="true"`. Сам элемент: `data-pinchmap-hit="link-icon"`, `data-node-id`, `aria-label` из i18n («Ссылка» / «Link»).
- **Зона касания** — 44×44px на экране при любом зуме (компенсация как у `.pinchmap-collapse-toggle`, `transform-origin` по центру). Видимая метка — 18px, как метка свёртывания: два элемента на ноде выглядят как одно семейство.
- **Поведение:** бабл открывается только тапом по иконке (выделяет ноду и открывает бабл). Тап по самой ноде, даже со ссылкой, только выделяет её, как обычно. Решение разработчика от 2026-11-25: так нет мелькания бабла при двойном тапе и нет задержки на одиночный тап.
- Цвет ноды на метку не влияет. Связь подходит к ноде посередине стороны, метка стоит в углу и связь не перекрывает.

### 4. Бабл ссылки

Создаётся на уровне документа, как `.pinchmap-done-bar`: `position: fixed`, экранные координаты, не масштабируется. Выглядит как родное меню Obsidian.

```css
.pinchmap-link-bubble {
  position: fixed;
  z-index: var(--layer-popover, 50);
  box-sizing: border-box;
  display: flex;
  flex-direction: column;
  min-width: 180px;
  max-width: min(320px, calc(100vw - 16px));
  max-height: 50vh;
  overflow-y: auto;
  padding: var(--size-2-3, 6px);
  border: 1px solid var(--background-modifier-border-hover, var(--background-modifier-border));
  border-radius: var(--radius-m);
  background-color: var(--background-secondary);
  box-shadow: var(--shadow-s);
}
.pinchmap-link-bubble[hidden] {
  display: none;
}
.pinchmap-link-bubble-button {
  display: flex;
  align-items: center;
  gap: var(--size-4-2, 8px);
  min-height: 44px;
  padding: 0 var(--size-4-3, 12px);
  border-radius: var(--radius-s);
  background: transparent;
  box-shadow: none;
  color: var(--text-normal);
  text-align: start;
  cursor: pointer;
}
.pinchmap-link-bubble-button:hover {
  background-color: var(--background-modifier-hover);
}
.pinchmap-link-bubble-target {   /* muted second line: note name or URL host */
  color: var(--text-muted);
  font-size: var(--font-ui-smaller, 12px);
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

- **Положение:** по горизонтали — по центру ноды (`getBoundingClientRect` ноды). По вертикали — **над нодой** с зазором 8px: на тач-устройствах палец закрывает то, что под ним. Если сверху не хватает места внутри видимой области канваса, бабл ставится под нодой с тем же зазором. По горизонтали бабл прижимается к видимой области канваса с полями 8px. Стрелки-указателя нет, как и у меню Obsidian.
- **Одна ссылка:** одна кнопка с главным текстом «Открыть ссылку» (i18n) и приглушённой второй строкой: имя заметки для вики-ссылки, домен для внешней. Слева иконка Lucide: `file-text` для вики-ссылки, `external-link` для внешней (16px, `--text-muted`). Иконку рисует `obsidian/` через `setIcon` или передаёт SVG, по тому же правилу о DOM.
- **Несколько ссылок:** по одной кнопке на каждую в порядке текста. Главный текст — подпись ссылки (alias или текст ссылки), вторая строка — цель. Длинный текст обрезается многоточием, ширина бабла не больше 320px. Если ссылок больше, чем помещается в 50vh, внутри бабла есть прокрутка. Одинаковые ссылки показываются один раз. Окончательное правило «какую ссылку открывать» — открытый вопрос спека. Если спек выберет одну ссылку, остаётся вариант с одной кнопкой.
- **Закрытие:** после нажатия кнопки (ссылка открывается, бабл закрывается); тапом или кликом в любом месте вне бабла; по Escape; по любому намерению на карте (панорама, зум, перетаскивание, двойной тап → ввод текста, долгое нажатие → меню, тап по другой ноде или пустому месту); при перезагрузке карты извне, изменении размера вида и скрытии вида. Таймера автозакрытия нет.
- **Двойной тап:** по ноде — только ввод текста, бабл не появляется (он открывается лишь с иконки). Если бабл открыт, двойной тап по ноде закрывает его и начинает ввод.
- **Фокус:** при показе бабл не забирает фокус у канваса. Кнопки — нативные `<button>`, кольцо `:focus-visible` берётся из темы. Escape закрывает бабл.
- Анимации появления нет.

### 5. Переход «сырой текст ↔ рендер»

- **Вход в редактирование** (двойной тап, Enter и т. д.): нода сразу переключается на сырой текст. `.pinchmap-node-markdown` скрывается, textarea показывает Markdown как есть (`**жирный**`, `[[Заметка]]`, `![[img.png]]`). Нода меняет размер под сырой текст: картинки исчезают и становятся строкой `![[…]]`. Это ожидаемо, переход мгновенный, без анимации. Бабл закрывается, иконка ссылки скрывается.
- **Поле ввода** остаётся как в фазе 1: фон `--background-primary`, обводка 2px акцентом, тот же шрифт и отступы.
- **Выход из редактирования:** до готовности нового рендера в ноде виден сырой текст (`.pinchmap-node-text`). Новый рендер строится в отсоединённом контейнере и подменяет старый одним кадром, когда `MarkdownRenderer.render` завершился. Так нода меняет размер один раз, а не на каждом промежуточном шаге. Картинки этому не мешают: их рамка фиксирована.
- **Открытие карты:** в первом кадре ноды показывают сырой текст, затем отрендеренные ноды подменяются пачкой в одном запланированном кадре. Мелькание сырого Markdown на долю секунды допустимо. Пустые ноды и скачки по одной ноде — нет.
- Перерендер — только при изменении исходного текста ноды. Выделение, цвет, перетаскивание, свёртывание Markdown не перерисовывают.

### 6. Вставка картинки

**Контекстное меню ноды** (`Menu` Obsidian, на мобильных — нижняя шторка). Новый пункт с подменю ставится сразу после «Дублировать», рядом с другими действиями над содержимым:

- **Вставить картинку** →
  - **Из хранилища…** — `FuzzySuggestModal` по картинкам хранилища, оформление штатное;
  - **С устройства…** — скрытый `<input type="file" accept="image/*">`. На iPhone и iPad он открывает системный выбор: Фото, Камера, Файлы. На ПК — диалог файла. Одна подпись на всех платформах;
  - **Из буфера обмена** — `navigator.clipboard.read()`. Вызывать нужно синхронно в обработчике выбора пункта: iOS требует жест пользователя.

  Многоточие стоит у пунктов, которые открывают диалог. Иконок у пунктов нет: у остальных `MenuItem` их тоже нет.
- **Во время ввода текста:** вставка картинки из буфера (Ctrl/Cmd+V, «Вставить» в системном меню iOS) через событие `paste` в textarea добавляет ссылку на картинку в позицию курсора. Отдельной кнопки картинки в панели «Готово» нет, в требованиях её тоже нет.
- **Обратная связь:** после вставки в ноде сразу появляется рамка-плейсхолдер 200×150, затем картинка. Спиннеров нет. Ошибки (нет картинки в буфере, отказ в доступе, сбой записи) показываются через `Notice` с текстом из i18n.
- Подписи — новые ключи в `obsidian/i18n.ts` (en + ru), английские значения по умолчанию лежат в `editor/`.
