# Pinchmap — правила работы

## Всегда работаем по фреймворку Bee

Любую задачу в этом проекте — фичу, доработку UX, багфикс, рефакторинг — ведём через Bee, а не правим код напрямую.

- Точка входа: `/bee:start` (триаж и выбор цепочки) или `/bee:sdd` (spec-driven development).
- Порядок: триаж → контекст → (discovery) → спек → архитектура → срезы по одному (код → тесты → проверка) → ревью.
- Код пишут, тестируют и проверяют специализированные агенты Bee (slice-coder, slice-tester, sdd-verifier, reviewer). Один срез за раз.
- Спеки и ревью лежат в `docs/specs/`, источник правды по поведению — `docs/pinchmap-requirements.md`.
- Границы модулей — `.claude/BOUNDARIES.md`; они же проверяются ESLint (`npm run lint`).

## Тривиальные задачи — упрощённый флоу

Тривиальная задача — это опечатка, конфиг, документация, правка в одну строку: одно очевидное решение, без вопросов к поведению. Для неё полный флоу SDD (discovery, архитектура, агенты по срезам) не нужен, но **короткий спек пишем всегда**.

1. Перед правкой создать файл `docs/specs/trivial/YYYY-MM-DD-<slug>.md` по шаблону ниже.
2. Сделать правку и прогнать проверки, которые её касаются (для кода — `npm run lint`, `npm test`, `npm run build`).
3. Отметить критерии `[x]` и закоммитить спек вместе с правкой.

Если по ходу выясняется, что решений больше одного или меняется поведение для пользователя, это уже не тривиальная задача: переходим на полный флоу (`/bee:start` или `/bee:sdd`).

Шаблон короткого спека:

```markdown
# <Название задачи>

> Тривиальная задача, упрощённый флоу Bee. Дата: YYYY-MM-DD.

**Зачем:** одно-два предложения — что не так и зачем менять.

**Что меняем:** файлы и суть правки.

**Критерии готовности:**
- [ ] ...
- [ ] Проверки прошли: ...

**Вне рамок:** что сознательно не трогаем (если есть).
```

## Прочее

- Документы проекта пишем по-русски, код и комментарии — по-английски.
- Перед коммитом: `npm run lint`, `npm test`, `npm run build`.
- Каждая пользовательская доработка повышает версию в `package.json`, `manifest.json` и `versions.json`.
