# Pinchmap — ручная проверка (фаза 1, слайсы 1–17)

Автотесты покрывают логику формата, раскладки, жестов и редактора. Этот чек-лист — то, что можно проверить только в живом Obsidian на устройствах. Отмечайте `[x]` и пишите замечания прямо под пунктом.

## Установка

### iPad / iPhone / ПК через BRAT (основной путь)

1. В Obsidian установите и включите плагин **BRAT** (Community plugins).
2. **BRAT: Add a beta plugin for testing** → `cutqxx/pinchmap`.
3. Включите «Pinchmap» в Сторонних плагинах. Обновления — **BRAT: Check for updates**.
4. Положите в хранилище тестовые карты: `docs/fixtures/h1-200-nodes.md` (200 нод) и любую свою заметку с `mindmap: true` во frontmatter.

### Сборка из исходников (ПК)

1. Нужен Node.js 22+:
   ```bash
   git clone https://github.com/cutqxx/pinchmap.git
   cd pinchmap
   npm ci
   npm run build
   ```
2. В хранилище создайте папку `.obsidian/plugins/pinchmap/` и положите туда `main.js`, `manifest.json`, `styles.css`.
3. Obsidian → Настройки → Сторонние плагины → включите «Pinchmap» (если нужно — нажмите «Обновить список»).

## Сначала главное: гипотезы H1 и H2 (iPad, iPhone)

Если что-то из этого не работает, это влияет на архитектуру — сообщите сразу.

- [ ] **H1, плавность.** Откройте `h1-200-nodes.md`. Время открытия — не больше пары секунд. 10 секунд водите пальцем по карте, несколько раз щипком зумьте от 10 % до 400 % и обратно. Нет заметных рывков, задержек, мерцания или размытого текста после остановки. Запишите модель устройства и впечатление.
- [ ] **H2, жесты Obsidian.** В книжной и альбомной ориентации проведите пальцем от левого и от правого края по карте — боковые панели Obsidian не открываются. Быстрый свайп от края не включает «назад». Щипок не масштабирует интерфейс Obsidian. Долгое нажатие на тексте ноды не вызывает выделение текста и лупу.

## Слайс 6 — выделение, добавление, удаление

- [ ] Тап / клик выделяет ноду, выделение видно (iPad + ПК)
- [ ] Тап / клик по пустому месту снимает выделение (iPad + ПК)
- [ ] У выделенной ноды две кнопки «+»: справа и снизу; легко попасть пальцем при любом зуме, в том числе 10 % и 400 % (iPad + ПК)
- [ ] На малом зуме тап по соседней ноде рядом с «+» выделяет соседа, а не добавляет ноду (iPad)
- [ ] Новая нода сразу выделена и на вводе; появляется экранная клавиатура (iPad + ПК)
- [ ] Новая нода, оставленная пустой, исчезает (iPad + ПК)
- [ ] Enter / нижний «+» на root — новый root прямо под его деревом (ПК)
- [ ] Delete / Backspace удаляет ноду с потомками (ПК)
- [ ] Delete / Backspace во время ввода правят текст, ноду не удаляют (ПК)
- [ ] Закончив ввод, кликните в поиск Obsidian и нажмите Backspace — в карте ничего не удалилось (ПК)
- [ ] Горячие клавиши карты не срабатывают в других вкладках Obsidian (ПК)

## Слайс 7 — ввод текста

- [ ] F2 открывает ввод выделенной ноды (ПК)

- [ ] Ctrl/Cmd+Enter завершает ввод и сохраняет текст (ПК)
- [ ] Над экранной клавиатурой есть кнопка «Готово», она завершает ввод и прячет клавиатуру; её не закрывает панель инструментов Obsidian (iPad + iPhone)
- [ ] При открытии клавиатуры нода сдвигается и видна над ней; уже видимая нода не двигается (iPad + iPhone, обе ориентации)
- [ ] Во время ввода можно сдвинуть карту — она не прыгает обратно на каждой букве (iPad)
- [ ] Многострочный текст после ввода показывается с теми же переносами (iPad + ПК)
- [ ] iPad с аппаратной клавиатурой: Tab, Enter, F2, Esc, Ctrl/Cmd+Enter работают как на ПК
- [ ] Ввод на японской или китайской раскладке: Esc и Ctrl/Cmd+Enter во время набора иероглифа не обрывают ввод (ПК или iPad)

## Слайс 16 — копирование, вставка и дублирование (версия 0.1.11)

- [ ] Порядок пунктов меню: «Добавить дочернюю», «Добавить соседнюю», «Цвет», «Копировать», «Вставить», «Дублировать», «Свернуть»/«Развернуть», «Вернуть в автораскладку», «Удалить» (iPad + ПК)
- [ ] «Копировать» (и Ctrl/Cmd+C на ПК) на ноде с детьми, затем вставка в обычную заметку — получается вложенный список без `^id` (iPad + ПК)
- [ ] «Вставить» (и Ctrl/Cmd+V) на выделенной ноде — ветка из буфера становится её последним ребёнком и выделяется; на iPad может появиться системная кнопка «Вставить» — нажмите её (iPad + ПК)
- [ ] Ctrl/Cmd+V без выделенной ноды создаёт новый root ниже всех деревьев (ПК)
- [ ] Скопируйте вложенный список из обычной заметки (с `-`, `1.`, чекбоксами, табами) и вставьте в карту — структура та же (iPad + ПК)
- [ ] Скопируйте несколько строк обычного текста и вставьте — каждая непустая строка стала отдельной нодой (iPad + ПК)
- [ ] «Дублировать» (и Ctrl/Cmd+D) ставит копию ветки соседом сразу после оригинала; цвета и свёрнутость сохранились, копия встала по автораскладке, даже если оригинал был сдвинут (iPad + ПК)
- [ ] Ctrl/Cmd+D делает ровно одну копию, а не две (ПК)
- [ ] Во время ввода текста ноды Ctrl/Cmd+C, V, D работают с текстом, а не с ветками (ПК)
- [ ] Вставка и дублирование отменяются одним «Отменить» (iPad + ПК)
- [ ] Закройте и откройте карту после вставки и дублирования — все ноды на месте, в Markdown нет повторяющихся `^id` (iPad + ПК)

## Слайс 17 — выделение нескольких нод и перемещение группы (версия 0.1.12)

- [ ] Долгое нажатие на пустом месте открывает меню; если отпустить палец не двигая, меню остаётся и ни один пункт не срабатывает сам (iPad, iPhone, палец и Pencil)
- [ ] После открытия меню поведите палец дальше 8 px — меню закрывается и рисуется рамка; после отпускания нода не создаётся (iPad, iPhone)
- [ ] Второй палец во время рамки отменяет её и начинает зум (iPad)
- [ ] Перетаскивание мышью по пустому месту рисует рамку; Space+перетаскивание и средняя кнопка по-прежнему двигают канвас (ПК)
- [ ] После отпускания рамки выделены только ноды, целиком попавшие в неё; частично попавшие и скрытые в свёрнутых ветках — нет (iPad + ПК)
- [ ] Shift/Cmd (macOS) или Shift/Ctrl (Windows) + клик добавляет ноду к выделению, повторный — снимает только с неё (ПК); Shift+тап с аппаратной клавиатурой (iPad)
- [ ] Ctrl+клик на macOS открывает меню ноды, и нода остаётся выделенной (ПК, macOS)
- [ ] Перетаскивание любой выделенной ноды двигает всю группу — при зуме 50 % и 200 %, группа из root и ребёнка другого root (iPad + ПК)
- [ ] Группа, отпущенная над другой нодой, родителя не меняет и подсветки цели нет (iPad + ПК)
- [ ] Перемещение группы отменяется одним «Отменить» (iPad + ПК)
- [ ] Перетаскивание одной ноды по-прежнему переносит её к новому родителю (iPad + ПК)
- [ ] Тап или клик по пустому месту и Esc снимают выделение со всей группы (iPad + ПК)
- [ ] Пока выделено больше одной ноды, кнопок «+» нет; Tab, Enter, F2, Ctrl/Cmd+D ничего не делают (ПК)
- [ ] Delete на группе удаляет все выделенные ветки, «Отменить» возвращает их одним шагом (ПК)
- [ ] Если в окне начать рамку во время ввода текста ноды, текст сохраняется (ПК)
- [ ] Карта в отдельном окне (popout): меню пустого места и рамка появляются в этом окне (ПК)
- [ ] **Приёмка фазы:** карта примерно на 200 нод с несколькими root, ручными сдвигами, цветами и свёрнутыми ветками, созданная на iPad, после синхронизации открывается на ПК без потерь; после правок на ПК — обратно на iPad; текст списка не испорчен, ID стабильны (iPad + ПК)
