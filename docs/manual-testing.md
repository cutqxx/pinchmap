# Pinchmap — ручная проверка (фаза 1, части 1a: слайсы 1–7)

Автотесты покрывают логику формата, раскладки, жестов и редактора. Этот чек-лист — то, что можно проверить только в живом Obsidian на устройствах. Отмечайте `[x]` и пишите замечания прямо под пунктом.

## Установка

### ПК (Windows, macOS, Linux)

1. Соберите плагин (нужен Node.js 18+):
   ```bash
   git clone -b claude/charming-curie-de8hz7 https://github.com/cutqxx/pinchmap.git
   cd pinchmap
   npm ci
   npm run build
   ```
   Либо возьмите готовый архив `pinchmap-plugin.zip` (в нём `main.js`, `manifest.json`, `styles.css`).
2. В хранилище создайте папку `.obsidian/plugins/pinchmap/` и положите туда `main.js`, `manifest.json`, `styles.css`.
3. Obsidian → Настройки → Сторонние плагины → включите «Pinchmap» (если нужно — нажмите «Обновить список»).
4. Положите в хранилище тестовые карты: `docs/fixtures/h1-200-nodes.md` (200 нод) и любую свою заметку с `mindmap: true` во frontmatter.

### iPad / iPhone

Через BRAT плагин пока не ставится (нет GitHub-релиза). Самый простой путь:

1. Установите плагин на ПК, как выше.
2. Синхронизируйте хранилище на iPad. Obsidian Sync: в настройках синхронизации включите «Установленные сторонние плагины». iCloud: папка `.obsidian/plugins/pinchmap/` синхронизируется сама.
3. На iPad: Настройки → Сторонние плагины → включите «Pinchmap».

## Сначала главное: гипотезы H1 и H2 (iPad, iPhone)

Если что-то из этого не работает, это влияет на архитектуру — сообщите сразу.

- [ ] **H1, плавность.** Откройте `h1-200-nodes.md`. Время открытия — не больше пары секунд. 10 секунд водите пальцем по карте, несколько раз щипком зумьте от 10 % до 400 % и обратно. Нет заметных рывков, задержек, мерцания или размытого текста после остановки. Запишите модель устройства и впечатление.
- [ ] **H2, жесты Obsidian.** В книжной и альбомной ориентации проведите пальцем от левого и от правого края по карте — боковые панели Obsidian не открываются. Быстрый свайп от края не включает «назад». Щипок не масштабирует интерфейс Obsidian. Долгое нажатие на тексте ноды не вызывает выделение текста и лупу.

## Слайс 1 — открыть, поправить, сохранить

- [ ] Файл с `mindmap: true` открывается картой (iPad + ПК)
- [ ] Файл без `mindmap: true` открывается обычным редактором (ПК)
- [ ] Команда «Открыть как Markdown» / "Open as Markdown" открывает карту в редакторе (iPad + ПК)
- [ ] Каждый пункт списка — нода со своим текстом, `^id` не виден (iPad + ПК)
- [ ] Ребёнок справа от родителя, соединён линией, дети столбиком по порядку (ПК)
- [ ] Двойной тап / двойной клик по ноде открывает ввод (iPad + ПК)
- [ ] Тап / клик вне ноды завершает ввод, нода показывает новый текст (iPad + ПК)
- [ ] Esc завершает ввод и сохраняет текст (ПК)
- [ ] Примерно через 1 с после правки файл сохранён — видно через «Открыть как Markdown» (iPad + ПК)

## Слайс 2 — формат без потерь

- [ ] Текст вне списка (до и после) на карте не показывается (ПК)
- [ ] `**жирный**`, `[[ссылка]]` в ноде показываются как есть, обычным текстом, с переносами строк (ПК)
- [ ] Файл с пустым списком открывается пустой картой без ошибки (ПК)

## Слайс 3 — ID, JSON, изменения извне

- [ ] Открыть карту без ID у пунктов и закрыть, ничего не меняя, — файл не изменился (дата изменения та же) (ПК)
- [ ] Файл с испорченным JSON-блоком (сломайте скобку в `%% ```json … ``` %%`) открывается картой с автораскладкой (ПК)
- [ ] …и показывается уведомление «раскладка не прочитана» (ПК)
- [ ] Правка файла в соседней вкладке Markdown или приход синхронизации — открытая карта перечитывает и показывает новое (iPad + ПК)
- [ ] Поправьте ноду и в течение секунды измените файл в другой вкладке — карта показывает внешнюю версию, ваша правка отброшена (ПК)
- [ ] …и появляется уведомление «Карта обновлена извне» (ПК)
- [ ] Измените файл извне, пока набираете текст в ноде, — перезагрузка происходит после окончания ввода, не во время (ПК)

## Слайс 4 — раскладка и несколько root

- [ ] Нода не шире 300 px, длинный текст переносится по словам (ПК)
- [ ] Каждый пункт верхнего уровня — отдельное дерево (ПК)
- [ ] Root визуально отличается (рамка, шрифт), цвета из темы (ПК)
- [ ] Светлая и тёмная тема — текст хорошо читается (ПК)
- [ ] Заметка с веткам первого уровня без `^id`: ветки распределены справа и слева; после правки и повторного открытия распределение не меняется, в JSON у левых `"side": "left"` (ПК)

## Слайс 5 — перемещение и зум

- [ ] Палец по пустому месту двигает карту без рывка в начале (iPad)
- [ ] Палец, начатый на ноде, карту не двигает (iPad)
- [ ] Щипок: точка между пальцами остаётся под пальцами; можно одновременно двигать (iPad)
- [ ] Зум упирается в 10 % и 400 % (iPad)
- [ ] Apple Pencil двигает и зумит как палец (iPad)
- [ ] Колесо / два пальца на тачпаде двигают; Shift+колесо — по горизонтали (ПК)
- [ ] Ctrl/Cmd+колесо и щипок тачпада зумят вокруг курсора; интерфейс Obsidian не масштабируется (ПК)
- [ ] Пробел + перетаскивание и средняя кнопка двигают карту; в Windows не появляется значок автопрокрутки (ПК)
- [ ] Перетаскивание левой кнопкой по пустому месту ничего не делает (ПК)

## Слайс 6 — выделение, добавление, удаление

- [ ] Тап / клик выделяет ноду, выделение видно (iPad + ПК)
- [ ] Тап / клик по пустому месту снимает выделение (iPad + ПК)
- [ ] У выделенной ноды две кнопки «+»: справа и снизу; легко попасть пальцем при любом зуме, в том числе 10 % и 400 % (iPad + ПК)
- [ ] На малом зуме тап по соседней ноде рядом с «+» выделяет соседа, а не добавляет ноду (iPad)
- [ ] Новая нода сразу выделена и на вводе; появляется экранная клавиатура (iPad + ПК)
- [ ] Новая нода, оставленная пустой, исчезает (iPad + ПК)
- [ ] Enter / нижний «+» на root — новый root прямо под его деревом (ПК)
- [ ] Delete / Backspace удаляет ноду с потомками (ПК)
- [ ] Delete / Backspace во время ввода правят текст, ноду не удаляют (ПК)
- [ ] Закончив ввод, кликните в поиск Obsidian и нажмите Backspace — в карте ничего не удалилось (ПК)
- [ ] Горячие клавиши карты не срабатывают в других вкладках Obsidian (ПК)

## Слайс 7 — ввод текста

- [ ] F2 открывает ввод выделенной ноды (ПК)
- [ ] Enter во вводе переносит строку и не создаёт ноду (iPad + ПК)
- [ ] Ctrl/Cmd+Enter завершает ввод и сохраняет текст (ПК)
- [ ] Над экранной клавиатурой есть кнопка «Готово», она завершает ввод и прячет клавиатуру; её не закрывает панель инструментов Obsidian (iPad + iPhone)
- [ ] При открытии клавиатуры нода сдвигается и видна над ней; уже видимая нода не двигается (iPad + iPhone, обе ориентации)
- [ ] Во время ввода можно сдвинуть карту — она не прыгает обратно на каждой букве (iPad)
- [ ] Многострочный текст после ввода показывается с теми же переносами (iPad + ПК)
- [ ] iPad с аппаратной клавиатурой: Tab, Enter, F2, Esc, Ctrl/Cmd+Enter работают как на ПК
- [ ] Ввод на японской или китайской раскладке: Esc и Ctrl/Cmd+Enter во время набора иероглифа не обрывают ввод (ПК или iPad)

## Как сообщить результат

Достаточно написать в чат номера пунктов, которые не прошли, и что произошло (лучше со скриншотом или записью экрана). Модель iPad и iPhone тоже пригодится для H1.

## Слайс 8 — новая карта и превращение заметки (версия 0.1.1)

- [ ] Команда «Новая карта» создаёт файл в папке для новых заметок (из настроек Obsidian) и открывает его картой (iPad + ПК)
- [ ] Кнопка «Новая карта» на ленте делает то же самое (ПК)
- [ ] Новый файл называется «Без названия», следующие — «Без названия 1», «Без названия 2» (ПК)
- [ ] В новой карте один пустой root, он сразу на вводе; на iPad появляется клавиатура (iPad + ПК)
- [ ] Команда «Превратить эту заметку в карту» есть только в обычных заметках (без `mindmap: true`) (ПК)
- [ ] После превращения заметка открывается картой; у пунктов появились `^id`, остальной текст и свойства не изменились (iPad + ПК)
- [ ] Заметка без списка превращается в карту с одним root по имени заметки (ПК)
- [ ] У карты, открытой как Markdown, есть команда «Открыть как карту» и кнопка в шапке; у обычных заметок их нет (iPad + ПК)
- [ ] После «Открыть как Markdown» → «Открыть как карту» повторное открытие файла снова показывает карту (ПК)

## Слайс 9 — добавление root и меню на пустом месте (версия 0.1.2)

- [ ] Долгое нажатие (0,5 с) на пустом месте открывает меню «Добавить ноду»; короткое нажатие или сдвиг пальца больше 8 px — нет (iPad)
- [ ] Правая кнопка мыши на пустом месте открывает то же меню (ПК)
- [ ] «Добавить ноду» создаёт root в точке вызова (левый верхний угол ноды) и сразу открывает ввод (iPad + ПК)
- [ ] Двойной клик по пустому месту создаёт root в точке клика (ПК)
- [ ] Двойной тап по пустому месту тоже создаёт root (iPad) — **решите: оставить так или только для мыши?**
- [ ] Настройки → Pinchmap: длительность долгого нажатия, по умолчанию 0,5; принимает «0,5» и «0.5»; значения вне 0,2–2,0 не применяются; новое значение сразу действует в открытых картах (iPad + ПК)

## Контекстное меню ноды (версия 0.1.3)

- [ ] Долгое нажатие на ноде открывает меню: «Добавить дочернюю», «Добавить соседнюю», «Удалить» (iPad)
- [ ] Правый клик по ноде открывает то же меню (ПК)
- [ ] После долгого нажатия отпускание пальца не выделяет другую ноду и не открывает ввод; системное меню iOS не появляется (iPad)
- [ ] «Удалить» удаляет ноду с потомками; выделяется соседняя или родитель; после этого Delete, Enter и Tab работают без лишнего тапа (iPad с клавиатурой + ПК)
- [ ] «Добавить дочернюю» / «Добавить соседнюю» создают ноду и открывают её на ввод с клавиатурой (iPad + ПК)
- [ ] Сдвиг пальца больше 8 px до срабатывания отменяет меню (iPad)

## Слайс 10 — undo / redo (версия 0.1.4)

- [ ] В шапке карты кнопки «Отменить» и «Повторить»; на iPhone они не прячутся в «⋯» и не обрезают заголовок; в них легко попасть пальцем (iPad + iPhone + ПК)
- [ ] Кнопки бледные и не нажимаются, когда отменять или повторять нечего (ПК)
- [ ] Ctrl/Cmd+Z отменяет, Ctrl/Cmd+Shift+Z и Ctrl+Y повторяют — в том числе на русской раскладке (ПК)
- [ ] Во время ввода текста Ctrl/Cmd+Z отменяет набранные буквы, а не действия на карте (ПК)
- [ ] Тап двумя пальцами отменяет, тремя — повторяет; щипок и перемещение двумя пальцами ничего не отменяют; от тапа зум заметно не дёргается (iPad)
- [ ] iOS не показывает своё меню «Отменить/Повторить» на тап тремя пальцами (iPad + iPhone)
- [ ] Удалите ветку и отмените — она вернулась на то же место, с теми же детьми (iPad + ПК)
- [ ] Нажмите «+» и сразу «Отменить» — исчезает только новая пустая нода (iPad + ПК)
- [ ] После отмены и повтора файл сохраняется (видно через «Открыть как Markdown») (ПК)
- [ ] После изменения файла извне обе кнопки становятся неактивными (ПК)
