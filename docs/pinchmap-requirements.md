# Pinchmap — требования

> Копия документа «Pinchmap — требования» (https://claude.ai/artifact/FtkThoP8SRb6DcUWNBGph7) от 2026-10-29. Источник правды — исходный документ.

## Цель и платформы

Pinchmap — плагин для Obsidian, в котором удобно строить mind map пальцами на iPhone и iPad и мышью с клавиатурой на ПК. Существующие плагины в каталоге неудобны на iPad — это главный пробел, который закрываем.

- Платформы: iOS (iPhone, iPad), macOS, Windows, Linux.
- Один и тот же файл открывается и редактируется на всех устройствах, синхронизация — средствами Obsidian (Sync, iCloud, Git).
- Тач-управление и управление мышью — равноправные, ни одно не «урезанное».
- Открытый исходный код, публикация в каталоге плагинов Obsidian.

## Хранение данных

Решение: карта хранится в обычном `.md` файле. Тексты нод — вложенный Markdown-список, а раскладка и стили — в скрытом JSON-блоке в конце того же файла. Так же устроены популярные плагины: Excalidraw хранит рисунки в Markdown с YAML frontmatter, чтобы они попадали в поиск и граф, а Mappy строит карту из заголовков и списков без особого формата.

Пример файла:

````markdown
---
mindmap: true
---
- Главная тема ^a1b2
    - Подтема с [[ссылкой]] ^c3d4
    - Ещё подтема ^e5f6
- Вторая главная тема ^g7h8

%%
```json
{"version": 1, "nodes": {"a1b2": {"x": 0, "y": 0, "pinned": false, "collapsed": false, "color": null}}, "style": {}}
```
%%
````

Правила формата:

1. Признак карты — `mindmap: true` во frontmatter. Плагин открывает такие файлы в своём виде, есть команда «Открыть как Markdown».
2. Каждый элемент верхнего уровня — отдельная главная тема (root).
3. У каждой ноды стабильный ID в виде block-ссылки `^id`. По нему JSON связывает раскладку с нодой. Бонус: на любую ноду можно сослаться из других заметок через `[[карта#^id]]`.
4. В JSON хранится только то, чего нет в тексте: координаты вручную сдвинутых нод, свёрнутые ветки, цвета, стили карты.
5. JSON не сжимаем — так он читается глазами и нормально мёржится при конфликтах синхронизации.

Почему не другие варианты:

| Вариант | Плюсы | Почему отказались |
|---|---|---|
| `.md` + скрытый JSON (выбран) | Читается без плагина, поиск, бэклинки, Obsidian сам обновляет [[ссылки]] при переименовании заметок | Нужно аккуратно парсить и сохранять ID |
| Obsidian Canvas (`.canvas`) | Открытый формат JSON Canvas из узлов и связей | Файл перехватывает встроенный Canvas, нет понятия «дерево», координаты обязательны для каждой ноды |
| Свой JSON (`.mindmap`) | Полный контроль | Без плагина нечитаем, не участвует в поиске и графе |
| Раскладка в `data.json` плагина (как в BloomMD) | Чистый Markdown | Раскладка живёт отдельно от файла и теряется при переносе карты |

## Структура карты и раскладка

На одном канвасе может быть несколько главных тем (root), у каждой — своё дерево. Ноды раскладываются автоматически, но любую можно сдвинуть рукой.

- **Несколько root.** «Добавить ноду» на пустом месте создаёт root: первую главную тему на пустом канвасе или ещё одну рядом с существующими.
- **Автораскладка.** Ветки первого уровня сначала добавляются справа от root. Когда правая сторона становится выше левой, новые ветки идут слева. Дети ветки встают ровно друг под другом, без пересечений.
- **Ручное перемещение.** Ноду или группу можно перетащить. Сдвинутая нода запоминает позицию, её дети едут вместе с ней. Есть команда «Вернуть в автораскладку» для ноды и для всей карты.
- **Смена родителя.** Перетаскивание ноды на другую ноду делает её дочерней для той. Во время перетаскивания цель подсвечивается.
- **Сворачивание веток.** У ноды с детьми есть индикатор свёрнуть/развернуть. У свёрнутой ноды показывается число скрытых потомков.
- **Связи** — только родитель–ребёнок, связей между разными ветками нет.

## Ноды

Все ноды ведут себя одинаково, root отличается только позицией в дереве и стилем по умолчанию.

**Создание**

- Тап по ноде выделяет её. У выделенной ноды появляются две кнопки: «+» справа — дочерняя нода, «+» снизу — соседняя.
- Новая нода сразу открывается на ввод текста.
- Тап по пустому месту снимает выделение.

**Редактирование текста**

- Двойной тап открывает ввод текста.
- Enter — новая строка. Ввод завершается тапом вне ноды, кнопкой «Готово» в панели над клавиатурой, Esc или Ctrl/Cmd+Enter.
- Текст — Markdown, рендерится как в Obsidian: жирный, курсив, код, [[вики-ссылки]], внешние ссылки, теги, картинки. Картинку можно вставить из хранилища, галереи или буфера: она сохраняется в папку вложений Obsidian и показывается в ноде миниатюрой.
- При открытии экранной клавиатуры канвас сдвигается так, чтобы редактируемая нода оставалась видна.

**Ссылки в нодах**

- Нода со ссылкой показывает иконку ссылки.
- Тап по такой ноде ссылку не открывает, а показывает всплывающий бабл с кнопкой «Открыть ссылку». Вики-ссылка открывает заметку, внешняя — браузер.
- Двойной тап открывает текст ноды на редактирование, ссылку можно поправить там.

**Контекстное меню ноды** (долгое нажатие или правая кнопка)

- Добавить дочернюю / соседнюю
- Цвет — дочерние ноды наследуют его, пока у них не задан свой
- Копировать, вставить, дублировать — работают с веткой целиком
- Свернуть / развернуть ветку
- Вернуть в автораскладку
- Удалить — удаляется вся ветка, отменяется через undo

**Undo / redo**

- Кнопки в тулбаре на всех устройствах.
- Жесты на тач-устройствах: тап двумя пальцами — undo, тремя — redo.
- Ctrl/Cmd+Z и Ctrl/Cmd+Shift+Z с клавиатуры.

## Управление

Каждое действие доступно и пальцем, и мышью; горячие клавиши работают на ПК и на iPad с аппаратной клавиатурой. Apple Pencil ведёт себя как палец. Долгое нажатие — 0,5 с (в iOS это стандарт; 1–2 с ощущаются как зависание), длительность настраивается.

| Действие | iPhone / iPad | ПК |
|---|---|---|
| Перемещение по канвасу | Один палец по пустому месту | Колесо и тачпад — скролл; Shift+колесо — по горизонтали; Пробел+перетаскивание или средняя кнопка |
| Зум | Щипок двумя пальцами | Ctrl/Cmd+колесо, щипок на тачпаде |
| Меню быстрых действий на пустом месте | Долгое нажатие | Правая кнопка |
| Добавить root | Долгое нажатие на пустом месте → «Добавить ноду» | Правая кнопка → «Добавить ноду» или двойной клик по пустому месту |
| Выделить ноду | Тап | Клик |
| Выделить несколько | Долгое нажатие на пустом месте и повести пальцем — рамка | Перетаскивание по пустому месту — рамка; Shift/Cmd+клик — добавить к выделению |
| Двигать ноду или группу | Перетащить ноду сразу, без выделения (движение начинается после порога в несколько пикселей); группу — после выделения рамкой | Перетащить ноду сразу; группу — после выделения рамкой |
| Сменить родителя | Перетащить ноду на другую ноду | Так же |
| Редактировать текст | Двойной тап | Двойной клик или F2 |
| Контекстное меню ноды | Долгое нажатие на ноде | Правая кнопка по ноде |
| Undo / redo | Тап двумя / тремя пальцами, кнопки в тулбаре | Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z |

**Горячие клавиши**

| Клавиша | Действие |
|---|---|
| Tab | Добавить дочернюю ноду |
| Enter | Добавить соседнюю ноду; в режиме ввода — новая строка |
| F2 | Редактировать выделенную ноду |
| Стрелки | Перейти к соседней, родительской или дочерней ноде |
| Delete / Backspace | Удалить ветку |
| Esc | Завершить ввод (также Ctrl/Cmd+Enter) или снять выделение |
| Ctrl/Cmd+C, V, D | Копировать, вставить, дублировать ветку |
| Ctrl/Cmd+/ | Свернуть / развернуть ветку |
| Ctrl/Cmd+0 | Вписать карту в экран |
| Ctrl/Cmd+= / − | Зум |

## Внешний вид, экспорт, производительность

**Внешний вид**

- По умолчанию карта наследует тему Obsidian (светлая/тёмная, акцентный цвет, шрифты) через CSS-переменные.
- В настройках плагина и отдельно для каждой карты можно поменять: палитру веток, форму нод, стиль связей (изогнутые/прямые), толщину линий, отступы, размер шрифта.
- Готовые пресеты стилей плюс «как в Obsidian».

**Экспорт**

- PNG, SVG, PDF — вся карта или выделенная ветка.
- Markdown — чистый вложенный список без служебного JSON и ID.

**Поиск**

- Поле поиска по карте: кнопка в тулбаре или Ctrl/Cmd+F.
- Совпадения подсвечиваются, между ними можно переходить; свёрнутые ветки с совпадением раскрываются.

**Встраивание в заметки**

- `![[карта]]` в обычной заметке показывает превью карты только для чтения.
- Тап или клик по превью открывает карту.

**Производительность** (рабочие целевые цифры)

- Карта на 1000 нод открывается быстрее 1 секунды на iPad.
- Зум и перемещение — без рывков (60 fps) при 1000 нод.
- Рисуются только ноды в видимой области, раскладка пересчитывается только для изменённой ветки.
- Автосохранение с задержкой около 1 секунды после последнего изменения.

## Открытые вопросы

Открытых вопросов нет. Решения, которые могут поменяться после первых тестов: правило переноса веток влево и порог начала перетаскивания.
