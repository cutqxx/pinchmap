# Создание нод с клавиатуры прямо из режима ввода текста

> Размер SMALL, риск LOW, флоу Bee SDD (SMALL). Дата: 2026-11-25. Версия: 0.1.16.

**Зачем.** Когда нода выделена, Tab создаёт дочернюю ноду, а Enter — соседнюю. Но во время ввода текста Tab просто завершает ввод (фокус уходит из поля), и новая нода не появляется. Приходится нажимать Tab дважды, а для соседней ноды — Esc и потом Enter. Писать карту подряд с клавиатуры неудобно.

**Решение разработчика.** Enter внутри ввода остаётся переносом строки: на iPhone и iPad без аппаратной клавиатуры нет Cmd, и другого способа перенести строку там нет. Новые ноды создаются по Tab и Cmd/Ctrl+Enter.

Это меняет критерий фазы 1 «Ctrl/Cmd+Enter завершает ввод и сохраняет текст»: теперь он ещё и создаёт соседнюю ноду.

## Критерии готовности

Во время ввода текста ноды:

- [x] Tab (без модификаторов) сохраняет текст, завершает ввод, создаёт **дочернюю** ноду редактируемой ноды и сразу открывает её на ввод — так же, как Tab на выделенной ноде
- [x] Ctrl+Enter и Cmd+Enter сохраняют текст, завершают ввод, создают **соседнюю** ноду сразу после редактируемой и открывают её на ввод — так же, как Enter на выделенной ноде. Для root создаётся новый root под ним
- [x] Enter и Shift+Enter переносят строку, как раньше; ввод продолжается, новых нод нет
- [x] Esc, «Готово» и тап вне ноды завершают ввод без новой ноды, как раньше
- [x] Если редактировалась новая нода и её текст пуст, Tab и Cmd/Ctrl+Enter просто убирают эту пустую ноду и завершают ввод, новая нода не создаётся (не плодим цепочку пустых нод)
- [x] Сохранённый текст и новая нода — два отдельных шага undo: первый undo убирает новую ноду (или её текст), второй возвращает старый текст
- [x] Во время набора через IME (японский, китайский) Tab и Cmd/Ctrl+Enter не обрывают ввод
- [x] Shift+Tab, Alt+Tab и Tab с Ctrl/Cmd не создают ноду
- [x] Сторона новой дочерней ветки и позиция нового root считаются по раскладке, в которой уже учтён сохранённый текст
- [x] README (таблица управления), `docs/manual-testing.md` и критерии фазы 1 в `pinchmap-phase-1-spec.md` описывают новое поведение
- [x] Версия поднята до 0.1.16 в `package.json`, `manifest.json`, `versions.json`
- [x] `npm run lint`, `npm test`, `npm run build` проходят

## Вне рамок

- Кнопка «новая нода» в панели над экранной клавиатурой.
- Shift+Tab для перехода к родителю или изменения уровня.
